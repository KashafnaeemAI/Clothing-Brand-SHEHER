Create a modern AI-powered skincare web application with a clean, premium, and responsive design.

Features:

1. Hero Section
- Beautiful skincare-themed background.
- Heading: "AI Skin Analyzer"
- Subheading: "Upload your selfie or talk with AI to get personalized skincare recommendations."

2. Image Upload
- Allow users to upload or capture a selfie.
- Display image preview before analysis.

3. AI Skin Analysis
- Analyze:
  - Skin Tone
  - Skin Type (Oily, Dry, Combination, Normal)
  - Acne
  - Pimples
  - Dark Spots
  - Pigmentation
  - Redness
  - Wrinkles
  - Pores
  - Under-eye circles
  - Hydration level
- Show results with progress bars and confidence percentages.

4. Personalized Recommendations
- Daily skincare routine.
- Morning and night routine.
- Recommended ingredients.
- Foods for healthy skin.
- Lifestyle tips.
- Products like Cleanser, Moisturizer, Sunscreen and Serum.

5. AI Chat Assistant
- Text chat interface.
- Users can ask skincare questions.
- AI responds with helpful skincare advice.

6. Voice Chat
- Add microphone button.
- Users can record voice messages.
- Convert speech to text.
- AI replies in both text and voice.
- Add speaker button to play AI responses.

7. Dashboard
- Save previous skin analysis.
- Compare before and after results.
- Show skin improvement history.

8. UI Design
- White and soft pastel colors.
- Premium glassmorphism cards.
- Smooth animations.
- Rounded buttons.
- Responsive for mobile, tablet and desktop.
- Professional skincare illustrations and icons.

9. Authentication
- Login and Signup.
- User profile.
- Secure data storage.

10. Footer
- Contact information.
- Privacy Policy.
- Terms of Service.
- Social media links.

Technology:
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Firebase Authentication
- Firebase Storage
- AI integration ready for OpenAI or Google Gemini Vision API.
- Voice input using Web Speech API.
- Text-to-Speech for AI responses.

The website should look modern, elegant, fast, and professional like a premium AI skincare platform.
